# ERROR_CODE_99

Basit bir memecoin projesi için web sitesi.

## Özellikler

- 24 saatlik geri sayım
- Gri tonlarında prompt ekranı
- Siyah arka plan
- Responsive tasarım

## Kurulum

1. Repository'yi klonlayın
2. `index.html` dosyasını bir web tarayıcısında açın

## Güncelleme

Her gün yeni bir prompt için `index.html` dosyasındaki `.prompt-content` içeriğini güncelleyin.

## Deployment

Vercel'e deploy etmek için:

1. GitHub repository'nizi Vercel'e bağlayın
2. Vercel otomatik olarak deploy edecektir
